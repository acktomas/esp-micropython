## 验证摇杆输出电压范围的完整方法（一）

### **✅ 一、如何看待“摇杆输出范围约 0.3V–3.0V，对应 ADC 值约 400–3700”？**

#### **✔️ 这个说法** ***\*基本正确且实用\******，原因如下：**

#### **1.** ***\*物理限制导致无法达到 0V/3.3V\****

- 大多数廉价模拟摇杆内部使用碳膜电位器，其机械结构决定了：
  - 滑块无法完全触达轨道两端
  - 存在 **死区（Dead Zone）**
- 因此实际输出通常为 **0.2V ～ 3.1V** 或 **0.3V ～ 3.0V**，而非理论上的 0～3.3V

#### **2.** ***\*ADC 转换验证（以 11dB 衰减为例）\****

ESP32-S3 的 ADC 在 `ATTN_11DB` 模式下：

- 输入范围 ≈ **0V ～ 3.3V**
- 输出数字值 = `(Vin / 3.3) × 4095`

| 电压 (Vin) | 理论 ADC 值             | 实测典型值 |
| :--------- | :---------------------- | :--------- |
| 0.0V       | 0                       | —          |
| **0.3V**   | `(0.3/3.3)*4095 ≈ 372`  | **≈400**   |
| **3.0V**   | `(3.0/3.3)*4095 ≈ 3723` | **≈3700**  |

> ✅ 所以 “400–3700” 是一个 **基于实测的经验值**，比理论值更贴近真实硬件。

------

### **⚠️ 二、如果仍按 0～4095 映射会有什么问题？**

```
angle = int(x_val * 180 / 4095)
```

但实际 x_val 范围是 400～3700：

| 摇杆位置 | 实际 ADC | 计算角度 | 真实期望角度 |
| :------- | :------- | :------- | :----------- |
| 最左     | 400      | ≈17°     | **0°**       |
| 中心     | 2048     | ≈90°     | 90° ✅        |
| 最右     | 3700     | ≈162°    | **180°**     |

👉 **结果：舵机永远达不到 0° 和 180°！行程损失约 ±18°**

这对机械臂夹取、云台转动等场景是**不可接受的**。

------

### **✅ 三、正确做法：*****\*动态校准映射\****

#### **推荐代码（替换原映射逻辑）：**

```
# 定义摇杆实际最小/最大 ADC 值（可调整）
JOY_MIN = 400
JOY_MAX = 3700

def map_joystick_to_angle(val, min_in=JOY_MIN, max_in=JOY_MAX, min_out=0, max_out=180):
    """将摇杆 ADC 值映射到 0～180°，支持任意输入范围"""
    # 限幅
    if val < min_in:
        val = min_in
    elif val > max_in:
        val = max_in
    # 线性映射
    return int((val - min_in) * (max_out - min_out) / (max_in - min_in) + min_out)

# 使用示例
x_angle = map_joystick_to_angle(adc_x.read())
y_angle = map_joystick_to_angle(adc_y.read())
z_angle = map_joystick_to_angle(adc_z.read())
```

> 💡 **优势**：
>
> - 即使不同摇杆个体差异大，也能满行程控制
> - 可通过实测微调 `JOY_MIN`/`JOY_MAX` 提升精度

## 验证摇杆输出电压范围的完整方法（一）

### 一、方法 1：硬件万用表直接测量（最精准）

这是验证电压范围的 “金标准”，能直接得到摇杆的真实输出电压，不受 ADC 配置、代码的影响。

#### 🔧 所需工具

- 数字万用表（普通入门款即可，如胜利 VC890C+）
- 杜邦线（公对母）
- 面包板（可选，方便接线）

#### 📝 操作步骤

1. **硬件接线**：按之前的引脚配置，先给摇杆供电（VCC 接 ESP32-S3 的 3.3V，GND 接 GND），VRX/VRY 暂时不接 ESP32-S3 的 GPIO，仅保留供电和接地。

2. **万用表设置**：将万用表调至「直流电压档（DCV）」，量程选「20V」（或「4V」，更精准）。

3. 测量 VRX（X 轴）电压   ：

   - 红表笔接摇杆的 VRX 引脚，黑表笔接 GND；
   - 缓慢将摇杆从最左侧拨到最右侧，记录**最小值**和**最大值**（如 0.32V ~ 2.98V）；
   - 拨到中间位置，记录中间值（约 1.65V，即 3.3V 的一半）。   

4. 测量 VRY（Y 轴）电压   ：
   - 红表笔接摇杆的 VRY 引脚，黑表笔接 GND；
   - 缓慢将摇杆从最下侧拨到最上侧，同样记录最小值、最大值、中间值。

5. **记录数据**：把测量结果记下来（如 X 轴：0.3V~3.0V，Y 轴：0.28V~3.05V），后续用于校准代码。

#### ⚠️ 注意事项

- 测量时摇杆要**缓慢拨动**，避免瞬间电压波动导致读数不准；
- 确保万用表黑表笔与摇杆 GND、ESP32-S3 GND 共地，否则读数会偏移；
- 若测量值接近 0V 或 3.3V，说明摇杆已到机械极限，无需强行拨动（避免损坏摇杆）。

#### 二、方法 2：软件 ADC 采样校准法（最便捷）

无需额外硬件，直接通过 ESP32-S3 的 ADC 采样读取电压值，适合没有万用表的场景，且能直接对应代码中的 ADC 值，校准更高效。

#### 📝 操作步骤

##### 1. 上传校准代码（可直接运行）

```
from machine import ADC, Pin
import time

# 初始化摇杆X/Y轴ADC（与项目引脚一致）
# GPIO4 = VRX（X轴），GPIO5 = VRY（Y轴）
vrx_adc = ADC(Pin(4))
vry_adc = ADC(Pin(5))

# 关键配置：11dB衰减（支持0-3.9V量程），12位采样（0-4095）
vrx_adc.atten(ADC.ATTN_11DB)
vrx_adc.width(ADC.WIDTH_12BIT)
vry_adc.atten(ADC.ATTN_11DB)
vry_adc.width(ADC.WIDTH_12BIT)

# 存储极值的变量
vrx_min = 4095  # 初始化为最大值
vrx_max = 0     # 初始化为最小值
vry_min = 4095
vry_max = 0

print("开始校准摇杆（持续10秒）：")
print("请缓慢、完整地拨动X轴（左右）和Y轴（上下），覆盖所有位置！")

start_time = time.time()
# 持续采样10秒，记录极值
while time.time() - start_time < 10:
    # 读取ADC原始值
    vrx_val = vrx_adc.read()
    vry_val = vry_adc.read()
    
    # 更新X轴极值
    if vrx_val < vrx_min:
        vrx_min = vrx_val
    if vrx_val > vrx_max:
        vrx_max = vrx_val
    
    # 更新Y轴极值
    if vry_val < vry_min:
        vry_min = vry_val
    if vry_val > vry_max:
        vry_max = vry_val
    
    # 实时打印当前值（方便观察）
    # ADC值转电压：电压 = ADC值 * 3.3 / 4095
    vrx_volt = vrx_val * 3.3 / 4095
    vry_volt = vry_val * 3.3 / 4095
    print(f"X轴：ADC={vrx_val} | 电压={vrx_volt:.2f}V | Y轴：ADC={vry_val} | 电压={vry_volt:.2f}V")
    time.sleep(0.05)

# 打印最终校准结果
print("\n=== 摇杆校准结果 ===")
print(f"X轴（VRX）：")
print(f"  ADC极值：{vrx_min} ~ {vrx_max}")
print(f"  电压极值：{vrx_min*3.3/4095:.2f}V ~ {vrx_max*3.3/4095:.2f}V")
print(f"Y轴（VRY）：")
print(f"  ADC极值：{vry_min} ~ {vry_max}")
print(f"  电压极值：{vry_min*3.3/4095:.2f}V ~ {vry_max*3.3/4095:.2f}V")
```

#### 2. 执行校准操作

1. 将代码上传到 ESP32-S3，打开串口终端（Thonny 的「Shell」窗口）；

2. 程序启动后，

   缓慢、完整地

   拨动摇杆：

   - X 轴：从最左→中间→最右，重复 3 次；
   - Y 轴：从最下→中间→最上，重复 3 次；

3. 10 秒后程序自动停止，终端会打印 X/Y 轴的 ADC 极值和对应的电压极值。

##### 3. 示例结果解读

```
=== 摇杆校准结果 ===
X轴（VRX）：
  ADC极值：380 ~ 3720
  电压极值：0.31V ~ 2.99V
Y轴（VRY）：
  ADC极值：410 ~ 3680
  电压极值：0.33V ~ 2.96V
```

→ 这说明该摇杆的实际 ADC 范围是 380-3720（X 轴）、410-3680（Y 轴），而非理论值 0-4095，后续只需将代码中的`adc_to_angle`函数参数替换为这些实际值即可。

### 三、将校准结果应用到项目代码中

假设校准后得到：

- X 轴 ADC 极值：380 ~ 3720
- Y 轴 ADC 极值：410 ~ 3680

只需修改`adc_to_angle`函数，替换掉原来的固定值，即可完全消除死区：

```
def adc_to_angle(adc_value, axis="x"):
    """
    校准后的ADC转角度函数
    axis: "x" 或 "y"，区分不同轴的极值
    """
    # 代入校准得到的极值
    if axis == "x":
        min_val = 380
        max_val = 3720
    elif axis == "y":
        min_val = 410
        max_val = 3680
    else:
        return 90  # 默认中间值
    
    # 限制ADC值在实测范围内
    adc_value = max(min_val, min(max_val, adc_value))
    # 线性映射为0-180度
    angle = (adc_value - min_val) * 180 / (max_val - min_val)
    return int(angle)

# 主程序中调用示例
servo1_angle = adc_to_angle(vrx_val, axis="x")  # X轴用x的极值
servo2_angle = adc_to_angle(vry_val, axis="y")  # Y轴用y的极值
```

### 四、关键注意事项

1. 机械死区 vs 电气死区  ：
   - 机械死区：摇杆拨到最极限位置时，物理上无法再移动，但电压 / ADC 值未到 0 或 4095（正常现象）；
   - 电气死区：校准后仍有一段 ADC 值范围，舵机无反应→需检查映射公式是否正确。

2. **多次校准取平均值**：摇杆的机械特性可能有轻微波动，建议重复校准 2-3 次，取平均值作为最终极值；

3. **电源稳定性**：校准前确保 ESP32-S3 的 3.3V 供电稳定（避免 USB 线接触不良），否则电压读数会偏移。

### 总结

1. 有万用表→用**方法 1**，直接测电压，精准度最高；
2. 无万用表→用**方法 2**，通过 ADC 采样换算电压，直接适配代码；
3. 校准后替换`adc_to_angle`函数的极值，即可完全消除舵机控制的死区，实现摇杆到舵机角度的平滑映射。

如果校准后发现摇杆某一轴的电压范围异常（如仅 0.5V~1.0V），大概率是摇杆硬件故障或接线接触不良，可先检查接线（VCC/GND 是否接牢），再更换摇杆模块重试。
